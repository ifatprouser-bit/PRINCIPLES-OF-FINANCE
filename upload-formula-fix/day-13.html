Annuity · sheet page 1, first table, the rows that start "C per Period"

ShapeFormula
Future valueFVt = C × {[(1 + r)t − 1] / r}
Present valuePV = C × {1 − [1 / (1 + r)t]} / r

On the real sheet this table sits under the misleading heading "The value of a single cashflow". Trust the row titles: "C per Period" means a repeating payment; "C Invested" or "C to Be Received" means one payment.

Growing annuity · sheet page 2

ShapeFormula
Present valuePV = A(1 + g) × [ (1 − (1 + g)n / (1 + r)n) / (r − g) ]

The first payment equals A(1 + g). Same formula in the pack's costume: PV = C1 / (r − g) × (1 − ((1 + g) / (1 + r))n), where C1 = A(1 + g).

Perpetuities · sheet page 1 row IV, and page 2

ShapeFormula
PerpetuityPV = C / r
Growing perpetuityPV = CF / (r − g), and it only works when r is bigger than g

Bond · sheet page 2, the boxed table

ItemFormula
Value of a bondBond value = C × [1 − 1/(1 + r)t] / r + F / (1 + r)t

C is the coupon paid each period, F is the bond's face value. The yield on a bond is found by trial and error: try a rate, price the bond, compare. Raising the rate lowers the bond value.

Payoff at maturity · sheet page 2

WhoPayoff
Senior debtMin(VT, FS)
Junior debt0 if VT < FS, otherwise Min(VT − FS, FJ)
EquityMax(VT − FS, 0)

FS is the amount promised to the senior lender on the maturity date. FJ is the amount promised to the junior lender. VT is the value of the firm's assets on that date. Equity is always what is left after every debt, and the three payoffs add to exactly VT. When there is junior debt too, use the equity line under "Not printed on the professor's sheet" below.
