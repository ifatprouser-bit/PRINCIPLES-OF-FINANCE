The last full paper before the exam. Whole course, real length, real clock.

How to sit this one

Read this, then start the clock and do not stop it.

This paper is meant to be hard. It has more questions that need two or three moves, more questions that hand you the answer and ask for the input, and more cases that sit exactly on a border.

A lower score here than on Mock 1 is normal, and it does not predict your exam score. The paper got harder, not you. Read the misses, not the percent.

Questions22, all multiple choice
Time150 minutes, about 6.8 minutes a question
AllowedThe formula sheet below, and a scientific calculator

During the paperNothing is shown. No score, no answers, no hints, until you submit

Formula sheet

This mirrors the professor's sheet. The rows under "Not printed on the professor's sheet" are pack additions. You do not have to learn any of it by heart. What you have to know is which one applies, and why.

Single cash flow
Compounding, one amountFVt = C × (1 + r)t
Discounting, one amountPV = C / (1 + r)t
The basic PV equationPV = FVt / (1 + r)t
Annuity
Future value of an annuityFVt = C × {[(1 + r)t − 1] / r}
Present value of an annuityPV = C × {1 − [1 / (1 + r)t]} / r

On the real sheet this table sits under the misleading heading "The value of a single cashflow". Trust the row titles inside it: "C per Period" means a repeating payment; "C Invested" or "C to Be Received" means one payment.

Growing annuity
Present value of a growing annuityPV = A(1 + g) × [ (1 − (1 + g)n / (1 + r)n) / (r − g) ]

On the sheet the first payment equals A(1 + g). The pack sometimes writes the same formula as PV = CF1 × [1 − ((1+g)/(1+r))n] / (r − g), where CF1 is the first payment. Same formula, because CF1 = A(1 + g).

Perpetuities
Present value of a perpetuityPV = CF / r
Present value of a growing perpetuityPV = CF / (r − g), and it needs r > g

The top line is next period's cash flow, not the payment made now.

Bond
Value of a bondBond value = C × [1 − 1/(1 + r)t] / r + F / (1 + r)t

C is the coupon paid each period. F is the bond's face value, the same thing the questions call par. The yield on a bond is found by trial and error: try rates until the calculated value matches the given price.

Payoff at maturity
Senior debtMin(VT, FS)
Junior (subordinated) debt0 if VT < FS, otherwise Min(VT − FS, FJ)
EquityMax(VT − FS, 0)

FS is the face value of the senior debt. FJ is the face value of the junior debt. VT is the value of the firm's assets at time T.

The sheet writes equity as Max(VT − FS, 0) and the class slides write it as Max(VT − FS − FJ, 0). Same rule, two cases. The owners are paid last, so they get what is left after all the debt. The safe test: your three payoffs must add up to exactly VT, every time.

Stocks
Price as all future dividendsP0 = D1/(1 + R)1 + D2/(1 + R)2 + D3/(1 + R)3 + …
Constant growthP0 = D1 / (R − g)
Supernormal growth, the steady tailPt = Dt × (1 + g) / (R − g)
Required returnR = D1/P0 + g
Holding period returnHPR = (P1 − P0 + D1) / P0

The rate is written R here. It is the same thing the rest of the sheet calls r. The sheet says HPR = r.

Stream and NPV
Stream of cash flowsPV = CF1/(1+r)1 + CF2/(1+r)2 + … + CFN/(1+r)N
Net present valueNPV = Σ CFi/(1+r)i − I0

I0 is the cost you pay at the start. An annuity formula always hands back a value one period before its first payment.

Not printed on the professor's sheet
Return on assetsROA = net income / total assets
Return on equityROE = net income / equity
Internal rate of returnThe IRR is the discount rate that makes NPV exactly zero

Questions in this paper use these three. The exam sheet does not print them, so know them by heart.
