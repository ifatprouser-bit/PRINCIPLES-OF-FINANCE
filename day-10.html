Payoff at maturity: who gets what

HolderPayoff
Senior debtMin(VT, FS)
Junior debt0 if VT < FS, otherwise Min(VT − FS, FJ)
EquityMax(VT − FS, 0) when senior debt is the only debt. With junior debt as well, equity is what is left after all of it: Max(VT − FS − FJ, 0)
MeaningVT is the value of the firm's assets at maturity. FS is the face value of the senior debt. FJ is the face value of the junior debt.
The three payoffs must add up to exactly VT, and equity can never be below zero. Run both checks on every payoff answer.

One cash flow

MoveFormula
Discounting, find PVPV = CFt / (1 + r)t
Compounding, find FVFV = PV × (1 + r)t

The same payment every period

ShapeFormula
PV of an annuityPV = A × (1 − (1 + r)−n) / r
FV of an annuityFV = A × ((1 + r)n − 1) / r
PV of a growing annuityPV = A / (r − g) × (1 − ((1 + g) / (1 + r))n)

Payments with no end date

ShapeFormula
PV of a perpetuityPV = A / r
PV of a growing perpetuityPV = CF1 / (r − g), and this needs r > g

Stocks, streams and projects

ItemFormula
Holding period returnr = (P1 − P0 + D1) / P0
PV of a streamPV = CF1/(1+r)1 + CF2/(1+r)2 + … + CFN/(1+r)N
Net present valueNPV = Σ CFi/(1+r)i − I0, where I0 is the cost today

In this course APR means the Absolute Priority Rule, not an annual percentage rate.
